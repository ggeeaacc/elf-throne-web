## 🔴 关键

### A-01 玫拉单人模式生命值冲突（10 vs 12）
- **原文出处**：【L193】"单人局为10点" vs【L56】人数总表与【L269】单人专章"12 / 6 点"。
- **歧义**：单人玫拉生命两处冲突。
- **裁定结果**：✅ **12 点**（推荐值）。
- **实现**：玫拉初始生命 12；P2→P3 阈值 floor(12/2)=6。

### A-02 凯-10「为妻而战」打出条件与效果自相矛盾
- **原文出处**【L354】："仅当古战场废墟场景下方存在危机卡时可打出……如果古战场废墟下方已无危机卡，改为造成6点伤害。"
- **歧义**：条件要求有卡、分支要求无卡，6 伤按字面永不触发。
- **裁定结果**：✅ **用户自定义**——打出条件不变（仅当古战场废墟下方存在危机卡时可打出）；对任意场景一张危机卡造成 4 点；**若除古战场废墟外的其他三个场景均已无危机卡，改为造成 6 点**。
- **实现**：condition = 古战场废墟危机数 ≥ 1；damage = (其他三场景危机数合计 == 0) ? 6 : 4。

### A-03 羁-08「师父与徒弟」（小鱼×巴爷）无结成路径
- **原文出处**：【L141】偏见需人类×精灵；【L143】结成唯一途径为共同击败偏见卡；【L146-152】关系表未列小鱼×巴爷。
- **歧义**：同族组合永不触发偏见，羁-08 存在却不可得。
- **裁定结果**：✅ **补充结成路径**（推荐值）——小鱼×巴爷处于同一场景并**共同清除任意一张危机卡**（两人均对其造成过伤害、由其中一人清除）即可结成羁绊，选取羁-08 或通用卡。
- **实现**：羁绊状态机新增转换路径（见 rules-spec §6.3）。

### A-04 失控替换羁-02 的细则
- **原文出处**【L153】："若激活"异世界同生死"前/后，小鱼出现失控，则将羁绊替换为……"
- **歧义**：激活前失控无卡可换；解除后是否回退。
- **裁定结果**：✅ **失控即发羁-02 并激活、解除后不回退**（推荐值）——无论激活前/后，小鱼失控瞬间小鱼×莉雅 立即获得羁-02 并视为已激活羁绊；失控解除后保持羁-02，不再换发羁-01；羁-02 主动自发卡当轮起可用（每轮限 1 次，计数独立）。
- **实现**：REPLACED 为终态；羁-02 视为"已激活羁绊"（可用于宝玉共鸣等判定）。

### A-05 "本回合"与"本轮"混用
- **原文出处**：大量卡牌"本回合内"；【L353】凯-09"持续至下一轮"。
- **歧义**：持续/统计窗口单位。
- **裁定结果**：✅ **一律按"本轮"**（推荐值）——所有"本回合内"持续至本轮 P4 结束；统计窗口（"本回合已受伤/已用偏见"）= 本轮；凯-09 延长一轮。
- **实现**：buff 生命周期挂 round 作用域。

### A-06 角色生命值归零（濒死）规则缺失
- **原文出处**：【L10】仅列"所有角色生命值均归零"判负。
- **歧义**：单角色归零后的处理未定义。
- **裁定结果**：✅ **出局**——生命归零角色立即移出游戏：立牌移除，不再参与行动、不占据场景、不再被任何效果选中或结算；全员归零判负（F3）不变。
- **实现**：出局为终态；其回合跳过；不参与偏见检查、危机卡目标选择、羁绊/传书等一切结算；涉及双方的羁绊卡效果不可用。

### A-07 失控"三回合"倒计时定义
- **原文出处**【L11】："三回合内未使小鱼脱离失控状态。"
- **歧义**：单位与检查点。
- **裁定结果**：✅ **小鱼的 3 个回合**——自进入失控起，每次小鱼回合开始时计数 +1，**第 3 次回合开始时仍失控 → 立即失败（F4）**。
- **实现**：检查点挂小鱼 TURN_START；决战中照常计数（A-37）。

## 🟠 高

### A-08 伤害结算管线顺序
- **原文出处**：各加减/翻倍/减半/转嫁卡面。
- **歧义**：多效果叠加顺序。
- **裁定结果**：✅ **用户自定义——按顺序即时结算**：多个效果按打出/声明顺序形成**有序效果链**，后声明的效果作用于先声明效果的结算结果之上；操作顺序由玩家自主决定；引擎实现为**确定性有序链**。
- **实现**：伤害 = 原子修正（+N / -N(钳0) / ×2 / ÷2(ceil) / 转嫁 / 分摊）按声明顺序依次折叠；减半在各自节点向上取整；每个减免节点各自带"最低减至 0"钳制；玫拉 P3 的 -1 为 Boss 侧节点（最低为 1）。

### A-09 "参与清除"的精确定义
- **原文出处**【L137, L143, L170】。
- **歧义**："参与"的口径。
- **裁定结果**：✅ **伤害轨迹定义**（推荐值）——自危机卡放置后对其造成过 ≥1 点实际伤害的角色为参与者；非伤害贡献不计；非伤害手段离场不算"清除"、无任何清除奖励。
- **实现**：危机卡挂 damageLog: Set<charId>。

### A-10 决战阶段的阶段边界
- **原文出处**【L197】："跳过第一阶段……其他阶段保留。"
- **歧义**：决战中 P3 偏见/危机卡的意义。
- **裁定结果**：✅ **用户自定义——决战跳过第一阶段和第三阶段**，直接从第二阶段开始，其他阶段保留（即决战 = P2' → P4' 循环）；**凯-05 在决战中仍可打出，但翻卡效果无场景可放：仅获得本回合 +2 伤，不翻危机卡**；决战中不触发偏见、不可结成羁绊、无沦陷检查对象。
- **实现**：BATTLE_LOOP = [P2', P4']；凯-05 battleMode 分支。

### A-20 危-07「黑暗迷雾」远程失效范围
- **原文出处**【L425】及 FAQ。
- **歧义**：方向与未列项。
- **裁定结果**：✅ **双向失效 + 巴-01/凯-10 补入远程清单 + 失效 = 不可合法选择目标**（推荐值）——迷雾场景内角色不可发起远程攻击，外部角色不可以迷雾场景内卡牌为远程目标；远程清单：莉雅被动（指定相邻场景时）、雅-09、鱼-08（指定相邻场景时）、装-02 主动、巴-01、凯-10。
- **实现**：目标合法性校验查询场景 debuff；攻击卡显式 remote 标签。

### A-24 失控期间的交互全集
- **原文出处**【L170, L185】。
- **歧义**：失控小鱼的交互白名单。
- **裁定结果**：✅ **被动客体化**（推荐值）——失控小鱼不能主动做任何事（含羁绊卡发动、装备主动），但可以被移动、被治疗、被援护/代受、被传书（暂存）；**羁-02 主动可由莉雅单方发动**；P4 手牌检查照常；失控伤害与危机卡轮末效果独立结算、互不构成连锁（失控伤害清除【暗】卡不给小鱼加侵蚀）。
- **实现**：失控态合法动作白名单；羁绊卡发动者权限字段。

## 增补裁定（v1.1 · QA 测试设计发现，用户已裁定）

### A-45 凯-05 与场景偏见限额的关系（修订 A-17 部分结论）
- **背景**：A-17 裁定凯-05"占用该场景本轮偏见限额"，QA 设计测试用例时发现：若 P3 已翻过偏见卡，凯-05 是否还能再翻，规则无覆盖。
- **原文出处**：【L142】"一张场景在一个轮次中最多因偏见触发一次额外危机。"【L349】凯-05"主动在当前场景触发一次偏见效果……每轮限用一次。"
- **裁定结果**：✅ **凯-05 可突破场景偏见限额**——即使本轮 P3 已在该场景翻过偏见额外卡，凯-05 仍可再翻一张；两条限额相互独立，**该场景每轮最多 2 张偏见额外卡（P3×1 + 凯-05×1）**。
- **实现**：偏见翻牌计数器拆为两个：p3PrejudiceUsed[scene] 与 kai05Used[scene]（后者同时受凯-05 每轮限 1 次约束）。

### A-46 玫拉 P1 暗影箭生命最低并列的处理
- **背景**：QA 设计 Boss 测试用例时发现：P1 暗影箭指定"生命值最低的角色"，并列最低时无处理规则（P2 宝玉之力原文有并列条款，P1 没有）。
- **原文出处**：【L210】"每轮结束后，玫拉会对场上生命值最低的角色发动暗影箭，造成1点伤害。"（对比【L216】P2 有"如果伤害最高者不唯一，则对所有并列者各造成1点伤害"）
- **裁定结果**：✅ **生命最低并列时，对所有并列者各造成 1 点伤害**（与 P2 并列条款口径一致）。
- **实现**：P1 暗影箭目标选择 = minHp 全集；宝玉共鸣减伤对每个目标独立生效。

### A-47 羁-01 分摊回血的触发单位（澄清性质，非数值变更）
- **背景**：engineer 按 spec 字面实现为"分摊后两支伤害各触发一次双方回血"（一次被击两人各回 2、合计 4 点），提请设计复核；复核认定与规则意图不符，报用户裁定。
- **原文出处**：【L391】"任意一方受到伤害时，两人各承担一半（向上取整）。每次承受伤害后，两人各恢复1点生命值。"
- **裁定结果**：✅ **按【伤害事件】触发**——一次被击（含分摊与各自减免）为一个事件；事件结算完毕后，**若至少一方实际承受伤害 > 0 → 触发一次，两人各恢复 1 点（每事件合计 2 点）**；双方份额均被减免至 0 → 不触发（即裁A-30"0 伤不触发"的本意）。未实际受伤的一方也同样恢复 1 点（原文"两人各恢复"）。
- **数值示例**：3 伤 → 分摊 2+1 → 触发 1 次 → 各回 1（净 1+0）；2 伤 → 1+1 → 各回 1（净 0+0）；1 伤 → 1+0 → 触发 1 次，未受伤方也回 1；双份均减至 0 → 不触发。
- **实现**：回血钩子挂在伤害事件结束点，而非每条分摊份额的应用节点。
