### 1.3 出局（生命归零）【裁A-06】

```
角色生命降至 0 的瞬间 → 出局（终态）：
  · 立牌移除；不再拥有回合（调度跳过）
  · 不占据场景（不参与偏见检查、危机卡目标选择、场景效果结算）
  · 不可被任何效果选为目标、不参与任何结算
  · 涉及双方的羁绊卡效果不可用；向其的传书不可发起
F3 判负不变：所有角色均出局 → 失败【L10】。
```

## 2. 全局状态机

### 2.1 顶层状态【裁A-10】

```
SETUP
  → ROUND_LOOP (round = 1..9)：P1 危机蔓延 → P2 破晓行动 → P3 偏见与羁绊 → P4 休整与倒数
  →（R9 的 P4 结束）→ BATTLE_PREP
  → BATTLE_LOOP (battle_round = 1..9)：**P2' 玩家行动 → P4' 休整（含玫拉行动）**
     ※ 决战跳过第一阶段与第三阶段【裁A-10】
  → END（胜利 / 失败）
```

- P2 回合顺序固定：小鱼 → 莉雅 → 凯尔 → 巴爷；未出场/出局角色跳过【L97-98】。

### 2.2 时间轴【L78-81】

D1：R1 清晨 / R2 黄昏 / R3 深夜；D2：R4-R6；D3：R7-R9 → 决战。每轮 P4 末推进一个时段【L158】。

### 2.3 失败检查点

| # | 条件 | 检查时机 |
|---|---|---|
| F1 | 决战 9 轮耗尽未击败玫拉【L194】 | 决战轮计数器溢出 |
| F2 | 任意场景危机卡 ≥ 阈值（4P/3P：4；2P/1P：5） | **仅每轮 P4 检查**【L94, L157】【裁A-19】 |
| F3 | 所有角色出局 | 持续（生命归零即出局，全员出局即判负）【裁A-06】 |
| F4 | 小鱼失控后，**其第 3 次回合开始时仍失控**【L11】【裁A-07】 | 小鱼 TURN_START（含决战，倒计时贯穿【裁A-37】） |

胜利：玫拉生命归零【L6, L221】。

## 5. 常规轮次：阶段严格步骤

### 5.1 P1 危机蔓延【L84-95】

```
1. n = 翻牌量(day, slot, mode)   # 3.2
2. FOR i = 1..n（逐张翻开逐张结算）:
   a. 若 day==2 且 slot==黄昏 且 i==1 → 翻开旁置通牒卡（计入 n）【L69】
   b. 否则牌库顶翻 1 张（牌库空 → 弃牌堆洗混重建【L95】）
   c. 目标场景：卡面指定 → 该场景；「通用」→ 玩家协商，不成则由本轮首位行动玩家定夺【L93】
   d. 正面朝上置于该场景下方，立即生效【L94】
3. 本阶段不做沦陷检查（F2 仅 P4【裁A-19】）
```

### 5.2 P2 破晓行动【L96-133】

```
TURN_START(角色 C):
  0. 若 C == 小鱼 且 C 失控：失控倒计时 +1；若计数 == 3 → F4 失败【裁A-07】
  1. 若 C 有待收书信且非失控/无法行动 → 结算传书接收（6.5）  # 获得 AP 之前【L182】
     （失控/无法行动 → 书信继续暂存【L185】）
  2. C 获得 AP = 3（三人局 4；决战 2）
       - 中度侵蚀修正 -1（小鱼；决战 2 → 1【裁A-25】）
       + 增益（凯-01 +1；雅-08 +1 仅下回合、不可累积【L332】）
  3. 自由行动（同一行动可重复，除非另述【L99】）
TURN_END
```

### 5.3 P3 偏见与羁绊【L139-154】（1P/2P 整阶段跳过【L54, L256】）

```
FOR EACH 场景 S:
  1. 找出 S 上"人类×精灵且尚未结成羁绊"的角色对：
     人类 = {小鱼, 巴爷}，精灵 = {莉雅, 凯尔}
     例外：小鱼×莉雅 永不触发偏见（含未激活期）【L153】
     可触发对：小鱼×凯尔、巴爷×莉雅、巴爷×凯尔【L149-152】
  2. 若存在 ≥1 对且 S 本轮 P3 尚未翻过偏见额外卡（P3 限额与凯-05 相互独立【裁A-45】）：
     - 仅翻 1 张：从危机牌库顶翻 1 张按 5.1-c/d 放置于 S【L141-142】
     - 多对同在时玩家共同选定一对为"触发对"【L142】
     - 记录关联 bondLead = (触发对, 该 cardId)（跨轮有效【裁A-16】）
```

**结成羁绊【L143-145】【裁A-16, A-18】：**

```
触发（路径一·偏见）：bondLead 中那张危机卡被其触发对"共同击败"——
   两人均对其造成过 ≥1 点伤害（伤害轨迹，见 6.1），且由其中任意一人清除；
   不限轮次；若该卡被第三方清除或被非伤害手段弃置 → bondLead 失效。
触发（路径二·同族）【裁A-03】：小鱼×巴爷 处于同一场景并共同清除任意危机卡（同上口径）。
结算：
  1. 双方各获 1 个金色羁绊指示物
  2. 选卡：在该对专属卡与通用卡（羁-03/04/05，羁-05 仅限人类×精灵对）中选 1 张
  3. 卡正面朝上置于两人角色卡之间
生效：主动效果双方均可免费使用、每轮限 1 次；被动永久【L144】；该对不再触发偏见【L145】
```

## 6. 核心机制算法

### 6.1 交战结算（对危机卡）【L134-138】【裁A-08, A-09】

```
ON 攻击卡对危机卡 K 造成伤害:
  1. 按有序效果链计算伤害（见 §11）
  2. 从 K 危机度扣除；用黑色侵蚀指示物在 K 上标记已损失危机度
     （单次攻击溢出伤害浪费）
  3. 若 K 危机度 ≤ 0 → 清除:
     a. K 入危机弃牌堆
     b. 「参与者」= 自 K 放置后对其造成过 ≥1 点实际伤害的角色（damageLog）；
        每位参与者获 1 个材料指示物（上限 4/人，溢出丢失）
     c. K 卡面清除奖励与基础奖励并存，一并结算【L415】
     d. 若 K 带【暗】且小鱼 ∈ 参与者 → 小鱼放 1 个侵蚀指示物【L138】
  4. 非伤害手段使危机离场（如羁-05 弃置）：不算清除，无任何清除奖励【裁A-09】
  5. 失控伤害清除：小鱼与同场景友方均不算参与、小鱼不获材料、不追加侵蚀【L170】
```

### 6.2 偏见触发
算法见 5.3；P3 偏见翻牌每场景每轮 ≤ 1 张，凯-05 翻牌每场景每轮 ≤ 1 张，**两条限额相互独立，同场景每轮最多 2 张偏见额外卡（P3×1 + 凯-05×1）**【裁A-45】；多对同在时玩家选定触发对【L142】。

### 6.3 羁绊状态机（每对角色）【裁A-03, A-04, A-16, A-18】

```
NONE ──(偏见对：共同击败 bondLead 卡)──────────────→ BONDED_ACTIVE（选专属/通用）
NONE ──(小鱼×巴爷：同场景共同清除任意危机卡)──────→ BONDED_ACTIVE（羁-08/通用）
BONDED_INACTIVE(仅小鱼×莉雅) ──(2 次成功传书)─────→ BONDED_ACTIVE（锁羁-01）
BONDED_INACTIVE / BONDED_ACTIVE ──(小鱼失控)──────→ BONDED_ACTIVE（羁-02，终态）
凯尔×莉雅：初始即 BONDED_ACTIVE（锁羁-07）
· 小鱼×莉雅 任何状态均不触发偏见；其他已激活对亦不触发【L145, L153】
· bondLead 记录（对, cardId），跨轮有效，卡被他人清除/弃置则失效【裁A-16】
```

**羁绊三态谓词（供效果判定调用，与引擎字段一一对应）：**

```
pairFormed(pair)   = state ≠ NONE
                     已结成羁绊（含未激活）。用途：偏见免疫判定——formed 即不再触发偏见
                     （小鱼×莉雅 开局即 formed=true，故全程不触发偏见【L153】）。
pairActive(pair)   = state == BONDED_ACTIVE
                     已激活。用途：羁绊加成是否生效、宝玉共鸣【L227】、羁-09/羁-01 主动可用性。
pairHasCard(pair)  = state == BONDED_ACTIVE（激活必持卡；羁-02 替换后依然成立【裁A-04】）
                     用途：凯尔·公爵威严翻倍判定【L338-339】【C8】。

小鱼×莉雅 时序示例：
  开局      → formed=true,  active=false, hasCard=false（不触发偏见，无加成，公爵威严不翻倍）
  2 次传书  → 发羁-01，三值全 true
  小鱼失控  → 换羁-02（若此前未激活则直接发卡激活），三值全 true，终态不回退
其他对：NONE →（结成事件）→ 三值同时置 true。
```

```
一次伤害 = 基础值 + 按"声明/打出顺序"排列的原子修正链，逐步折叠（后项作用于前项结果）：
  原子修正类型：
    ADD(+n)        攻击加值：屠龙者之血（仅攻击卡【裁A-12】）、精灵神射、装备、
                   风之加护/弩炮掩护/精灵荣光/凯-05/羁绊加值、净化指示物、信物、小剑小盾(+1)
    MULT(×2)       翻倍（巴-06 等）
    HALVE(÷2,ceil) 减半（节点处向上取整）
    REDUCE(-n,0)   减免：龙鳞护甲、守护之姿、巴-03、小剑小盾(-1)、公爵威严、羁-04、传-03、
                   宝玉共鸣（仅玫拉轮末效果【裁A-36】）；每个 REDUCE 节点各自钳制下限 0
    BOSS_P3(-1,1)  玫拉 P3 特殊减免，钳制下限 1
    REDIRECT(承受者) / SHARE(总额守恒分摊)
顺序规则：
  · 链中顺序 = 玩家实际声明/打出各效果的顺序（玩家自主决定，引擎按确定性有序链折叠）
  · 代受/转嫁：多人声明同一代受目标时由玩家决定承受者；伤害按最终承受者的减免链计算【裁A-29】
  · 分摊（羁-01/羁-10/巴-09）：总额守恒——ceil(半) 与 floor(半) 各一人承担，谁承高份由玩家定；
    分摊后各自再走自己的减免链；实际承受 0 伤不触发羁-01 回血【裁A-30】
  · 巴-05"失去生命"不是伤害：不入链、不可代受不可减免【裁A-29】
终端应用：扣生命/危机度/护盾 → 衍生效果（侵蚀 T1-T5、弃牌、材料奖励、反击）
```
